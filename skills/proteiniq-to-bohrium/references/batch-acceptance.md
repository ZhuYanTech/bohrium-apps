# 批量筛选与验收记录

批量任务开始时记录范围、ProteinIQ 排序依据和日期、玻尔项目、当前镜像配额与已使用数量。按用户授权的数量推进。核对工具等价性时记录能支持判断的链接和搜索词。

同一算法或等价 App 已经存在时，按用户要求跳过或续做。若名称相似但用途不同，记录比较依据。需要替换候选时，按同一份热度列表从后续名次继续。

## 单个 App 兼容性表

| 核对项 | 来源工具的实际行为及证据 | 玻尔实现及证据 | 验收样例、预期、实测与差异 |
| --- | --- | --- | --- |
| 输入 | 扩展名、文件数量、文本或文件入口、大小限制 | 表单接受范围及后端解析 | 每种承诺格式、空输入、无效输入、混合批次 |
| 参数 | 名称、类型、默认值、模式、条件和互斥规则 | 生成的参数声明及测试页实际控件 | 默认、非默认、冲突、边界及无效组合 |
| 输出 | 文件、字段、精度、顺序、缺失值和未评估语义 | 实际下载产物 | 相同样例核对数值、列数、分类和错误反馈 |
| 双语文档 | 业务语义和公开样例 | 实际部署支持及替代入口 | 镜像与 App 共八份文档逐页重开验收，来源只链接开源 GitHub 仓库 |

平台网页的单行控件和批量上传限制需要用实际页面确认。若计算入口支持多行而网页只能单行，记录文件上传等已测试替代方式。报告功能覆盖时同时写明保留的差异。
