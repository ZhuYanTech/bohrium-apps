# 玻尔应用兼容性验收清单

每个应用用独立自建镜像及独立镜像仓库。保留已用镜像标签和摘要，修订版本绑定对应应用的新版镜像。

## 脂肪族指数

| 核对项 | 验收样例 | 预期 |
| --- | --- | --- |
| 裸序列、内部空白、大小写 | `AV IL` | `Sequence,4,292.50` |
| FASTA/TXT | 一条或多条标准序列 | 首段 ID、固定排序、稳定结果 |
| CSV 格式 | `id,sequence` 的胰岛素 A/B；`name,seq` 带引号变体 | 88.10 与 84.33；列别名及引号解析正确 |
| PDB | 双模型，两条链，含 MSE | 仅首模型；链 A 50.00，链 B 290.00 |
| RCSB | 1UBQ | 76 残基，100.00 |
| 无效数据 | 空记录、非法残基、不完整 CSV | 明确报错，整批停止 |
| 输出 | 两份 CSV | 结果表三列、两位小数；明细保留计数与六位小数 |

## PoseBusters

| 核对项 | 验收样例 | 预期 |
| --- | --- | --- |
| 三态汇总 | 全通过、部分空值、失败加空值、全部空值 | 通过、失败、未评估分别计数；空值从不计为通过 |
| 默认和详细报告 | 1IA1 重对接 | 28/28，详细诊断不改变汇总 |
| 输入模式 | ZIP 内 `pairs.csv`，同一姿势重复配对 | 两行按配对顺序保留，分别执行 12 与 28 项 |
| 验证模式 | 自动、手选、快速、自定义 | 支持实际已声明预设；缺少该模式所需输入时明确报错 |
| 格式和 Top N | Short/Long/CSV；两条姿势取第一条 | 对应原生报告可下载；仅第一条出结果 |
| 受体处理 | 默认保留；显式或自动移除 | 默认结果不受自动移除影响，运行元数据记录实际操作 |
| 运行记录 | 普通任务和逐配对目录 | 保存版本、模式及解析后的配置 |
| 输出状态 | 开发者测试页、免费 CPU 批处理 | 检查表单实际字段和云端下载结果，分别记录两者状态 |

## 文档及限制

- [ ] 镜像和 App 各保存中文/英文介绍及帮助，刷新验证实际渲染，去掉模板和重复段落。
- [ ] 来源链接只指向开源 GitHub 仓库；可在操作说明中指明实际使用的数据服务。
- [ ] 写清可接受扩展名、文件数量、必填条件、参数默认值、三态结果和误差精度。
- [ ] 对照来源时区分业务兼容与网页交互：当前玻尔为离线表单与下载，批量配对采用 ZIP 顺序；未复制内嵌结果排序、信用计费和按账户限制。自定义正式检查列名称需要唯一。
