## Ramachandran Plot

Plot protein backbone dihedrals and classify each residue against six reference distributions.

A Ramachandran plot compares each measurable residue’s backbone φ and ψ angles with its reference distribution. The six classes are general, glycine, cis-proline, trans-proline, pre-proline, and isoleucine/valine. Inspect outliers in the structure since strained conformations can also occur in well-refined models.
