## 准备输入

- **待检查姿势（必填）**：上传 SDF、MOL、MOL2 或 PDB。批量检查共用受体的多个姿势时，建议把姿势放在一个多记录 SDF 中。
- **受体（可选）**：上传 PDB（CIF 或 ENT 请先转换为 PDB），或填写四位 PDB 编号。两者同时提供时，以上传文件为准。
- **晶体参考（可选）**：上传 SDF 或 MOL。完整重对接检查需要同时提供受体。只给晶体参考时，执行 18 项检查并跳过口袋相容性。
- **受体中待移除的配体残基（可选）**：填写残基名，多个用逗号分隔。受体保留待检查的配体时，可能出现配体与自身重叠；水和辅因子应保留供检查。

## 运行和读取结果

在 App 上传文件，选择 CPU 后提交。若需要额外的数值诊断，可勾选「明细表附带具体数值」。数值诊断只加入明细表，汇总判定仍使用同一组正式检查。

- `summary.csv`：逐姿势查看通过项数、未通过项和总体有效性（PB-valid）。
- `results.csv`：逐检查项的明细。
- `report_zh.md`：中文报告；`posebusters_raw/` 保存原始明细和运行中生成的受体文件。

## 复现实例

使用 PoseBusters 自带的 1IA1 基准：将晶体配体分别作为待检查姿势和晶体参考，并使用已移除该配体的受体文件。该正例预期通过重对接模式的全部 **28 项**检查。RMSD ≤ 2 Å 只用于具有参考姿势的比较。
